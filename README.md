# Appussi-stock
Stock of the apps developed by Matteo Mussillon

## App

| App | Cartella | Descrizione |

| Dream MLB (EN) | [`dream-mlb/`](dream-mlb/) | Fast MLB player-career simulator in English (same engine family as Dream NHL): Draft wheel, training, 162-game seasons, awards, Wild Card to the World Series and Game 7. React + Vite source in [`dream-mlb-src/`](dream-mlb-src/), static build in [`dream-mlb/`](dream-mlb/). |
